# 05. 회의록 1차 — 컨셉·역할·환경 정리 (2026.11.21 16:30, 약 16분)

> 원본: 네이버 클로바노트 녹취. 기획 반영본은 01~04 문서 참고

## 1. 결정 사항
| 항목 | 결정 |
|---|---|
| 컨셉 | 카테고리를 **채널**로 바꾼 TV. 채널을 한 방향(다음)으로만 넘기며 시청 (제약) |
| 채널 | **채널 1개 = 카테고리 1개** (예: 예능, 금융). 개수는 5~7개 권장, 추후 확정 (회의 중 "5개"는 임시 수치였음, 너무 많으면 고르는 피로가 생김) |
| 시간 제약 | 두지 않음. 식사 20분 동안 자유롭게 채널 이동 |
| 영상 소스 | 유튜브 링크 + 웹에 유튜브 플레이어 임베드 (크롤링 가능 여부 확인) |
| 디자인 톤 | TV 모양 + 투박한 리모컨. 사이버 흡연실 같은 레트로 감성. 랜덤·엉뚱함 |
| 화면 | 모바일 뷰 고정, 데스크톱은 양옆 여백(로고) |
| 플랫폼 | 웹 + iOS·Android 웹뷰 앱 (웹 가이드의 APK·앱 연결 항목 반영) |
| 배포 | 클라우드 배포 필수(로컬호스트 0점). 웹은 Vercel 등 |
| 저장소 | 조직 아닌 개인 GitHub 저장소 1개, 한 명이 생성해 공유 |
| 소통 | 자료 공유는 카톡방, Figma 작업 환경은 디자이너가 1개 생성 |
| 프로젝트명 | 미정 (오래 고민해야 해서 임시로 "너리너리 해커톤") |

|---|---|---|

| 디자인 | 1 | Figma 환경 생성, TV·리모컨 레퍼런스 탐색, 모바일 뷰 디자인 |
| 웹 | 1 | 유튜브 플레이어 임베드, 모바일 레이아웃, 에러·빈 상태·스켈레톤 |
| 서버 | 2 | 채널·영상 API, DB, 클라우드 배포, 인프라 구성도·ERD |
