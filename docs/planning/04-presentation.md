## 슬라이드별 보강 내용 (Figma 11.22 기준)

### 02 원인과 근거 (3장)
- 02-1 "밥친구 왕중왕전 최후의 승자는?": 배달의민족 「나만의 혼밥 스킬」 이벤트 98,597개 응답(2025.7.14~, 약 2주, 2025.8.1 보도자료), 혼밥 시 영상(TV·OTT)을 본다 91% / 음악 5% / 거울 3.4% / SNS 0.6%
- 02-2 "볼 게 너무 많아서 생기는 권태": Talker Research·UserTesting, 2024.11.2~7 미국 성인 2,000명, 스트리밍 구독자가 고르는 데 연 평균 110시간(약 5일, 하루 약 18분)
- 02-3 "고르다 지치는 건 개수 때문만은 아니에요": Chernev·Böckenholt·Goodman (2015) 선택 과부하 메타분석. 과제 난이도·선택지 복잡도·선호 불확실성·의사결정 목표가 영향
- 한계 한 줄 필수: 02-1은 이벤트 응답(표본 편향 가능), 02-2는 미국 조사. 사실과 가설을 구분해 말한다. 출처 URL은 슬라이드 하단에 있다

### 03 해결 방안 (3장): 기획 의도 + 제약 일부 허용 논리
- 03-1 "고르지 않고, 채널을 돌린다": TV·리모컨 그래픽 히어로 ("익숙한 TV 리모컨 채널 돌리기 / 카테고리별 유튜브 영상 바로 재생")
- 03-2 서비스 소개: "밥송국은 밥 먹는 20분을 위한 채널형 영상 큐레이션 서비스" / "고르는 수고는 빼고, TV 켜는 습관은 그대로"
- 03-3 가치 3가지: 하나 켜자마자 재생 / 둘 고민 없는 시청 / 셋 엉뚱한 재미 ("밥 먹는 20분, 고르다 끝나지 않게 해드릴게요")
- 기획 의도: "고르는 일"을 없애는 게 아니라 "고르는 행위를 채널 돌리기라는 놀이로 바꾼다"
- 제약 일부 허용(11.21 결정)을 한 줄로 설명: 숫자 키(한 자리, 0~9)는 허용 / 채널 ▼(이전)·영상 직접 선택·검색은 계속 제외 → "고를 수는 있어도 비교·탐색은 못 한다". 0번은 숫자 키로만 가는 컬러바 이스터에그, ▲ 순환은 1~9(9 다음은 1)
- 예상 반박 "숫자 키·새로고침이 있으면 결국 고르는 거 아니냐"에 대한 답은 백업 B17에 있다

### 04 MVP 선정: 필수 / 보조 / 요건 구분
- 장표는 플로우 3단(접속·TV 꺼짐 → 전원 → S2 시청 → 채널 전환)과 화면 S1~S4 카드로 구성
- 필수(Pain Point 직결): F1 채널 목록, F2 영상 재생, F3 채널 이동, F8 새로고침
- 필수 보조(기술 제약 대응): F7 전원 켜기/끄기 (브라우저 자동재생 차단 대응)
- 보조: F4 랜덤 연출, F6 전체화면, F9 편성표 팝업
- 요건: F5 앱 실행. 발표에서는 "심사 요건"이라 말하지 않고 "iOS·Android·웹 동일 경험"으로 표현
- 제외: 로그인·검색·채널 ▼·추천 알고리즘 (제약 컨셉에 반함)

### 05 사용자 플로우·화면 구성: 디자인 해석
- "기획 → 디자인 해석" 한 줄: 제약 → 한 자리 번호 리모컨 / 소리 문제 → 꺼진 TV와 전원 버튼 / 선택 부담 → 활성 버튼 최소화
- 장표 하단 "시청 중 조작" 4가지(다음 채널·숫자 키 / 새로고침 / ? 편성표 / 전체화면)를 한 줄씩 짚는다
- 디자인 시스템(Retro Pixel)은 B13(컬러·폰트·아이콘)·B14(컴포넌트), 정보구조도는 B10, 상세 플로우는 B11로 둔다

### 06 예외·에러 처리
