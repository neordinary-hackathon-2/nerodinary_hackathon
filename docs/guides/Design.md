# 1. 시간대별 가이드

> ⏰ **제출 마감 11.22 · 07:30**
> 07:20부터 프로젝트를 제출해 주세요. 발표 준비 중에도 07:30 제출 마감을 지켜 주세요.


## 01. 16:40—19:00 — 아이디어와 초기 세팅
- 디자인 작업 환경을 설정해 주세요.
  - 프레임 크기를 정해 주세요. 안드로이드는 360 × 740px, iOS는 402 × 874px을 기준으로 하고, 웹은 앱 플랫폼 중 하나를 선택해 모바일 뷰로 제작해 주세요.
  - 그리드를 설정해 주세요.
  - 폰트와 컬러 등 디자인 시스템 초안을 정해 주세요.
- 와이어프레임과 메인 페이지 디자인을 진행해 주세요.


## 02. 19:00—05:00 — 프로젝트 개발
- 서브 페이지와 베리언트 페이지를 디자인해 주세요.
  - 추가 뎁스의 페이지를 구성해 주세요.
  - 오류 안내와 재입력 화면도 준비해 주세요.
- 디자인 시스템을 확정해 주세요.
  - 폰트, 컬러, UI 컴포넌트를 정리해 개발자에게 전달해 주세요.
- 완성된 페이지와 컴포넌트는 수시로 공유해 주세요.
  - 개발이 이어질 수 있도록 정해진 시간 안에 작업물을 전달해 주세요.
- 구현된 페이지를 확인하고 필요한 부분을 수정해 주세요.
  - 개발 화면과 디자인 시안이 일치하는지 함께 확인해 주세요.


## 03. 05:00—07:40 — 최종 점검과 발표 준비
- 디자인을 검토하고 마무리해 주세요.
  - 제작한 페이지를 최종 검토해 주세요.
  - 누락되거나 오류가 있는 화면은 확인 후 수정해 주세요.
- PPT와 발표 자료를 제작해 주세요.

# 2. 유의사항

1. 작업량을 늘리기보다 핵심에 집중해 주세요.
2. MVP의 핵심 기능을 중심으로 디자인해 주세요.
3. 기획자와 의논하며 와이어프레임을 빠르게 정리해 주세요.
4. 전체 화면 수와 구조를 먼저 파악하고, 작업량과 소요 시간을 가늠해 주세요.
5. 디자인 시스템과 브랜딩 방향을 초반에 빠르게 정해 주세요.
6. 기획자·개발자에게 디자인을 수시로 공유하고 피드백을 주고받아 주세요.
7. 시간 내 구현하기 어려운 그래픽 효과나 애니메이션은 제외하는 것을 권장해요.
8. 디자인을 빠르게 진행하고 QA 시간을 확보해 주세요.
9. 개발이 진행되는 동안 발표 자료 제작을 준비해 주세요.
10. 발표 자료는 주요 내용에 집중하고, 시각적인 꾸밈에는 필요한 만큼만 시간을 써 주세요.

# 3. 심사기준

**기본 총점 100점**



## 01. 창의성 (10점)
#### 채점 방법
- 해커톤 주제와 목적에 맞는 디자인인지 살펴봐요.
- 문제 해결에 효과적인 디자인 솔루션을 제안했는지 확인해요.


## 02. 실현가능성(System w.개발자) (20점)
#### 채점 방법
- 효율적인 디자인·개발 협업을 위해 디자인 시스템과 기능 정의가 잘 정리되어 있는지 확인해요.
- 개발자와 협력해 구현할 수 있는 수준인지 살펴봐요.


## 03. 실현가능성(목적 실현 w.기획자) (20점)
#### 채점 방법
- 기획 의도를 디자인으로 어떻게 해석했는지 살펴봐요.
- 초기 기획이 시각적으로 얼마나 잘 표현되었는지 확인해요.


## 04. 비주얼 디자인 (25점)
#### 채점 방법
- 색상, 타이포그래피, 이미지가 적절하게 사용되었는지 살펴봐요.
- 전체적인 조화와 일관성을 확인해요.


## 05. 사용자 경험 (User Experience, UX) (25점)
#### 채점 방법
- 인터페이스가 직관적인지 살펴봐요.
- 사용자의 흐름이 자연스럽게 이어지는지 확인해요.
