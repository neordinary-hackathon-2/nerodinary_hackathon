# 2. 유의사항

1. 화면 수를 최소화하고, 로그인·회원가입은 꼭 필요한 경우에만 포함해 주세요.
2. 소요 시간을 예측하기 어려운 기능은 가능한 한 제외해 주세요.
3. 기능의 우선순위를 정하고 순서에 맞춰 개발해 주세요.
4. 배포된 서버와 API가 정상적으로 연동되는지 확인해 주세요.
5. 기획 단계에서 패키지 관리 도구, CSS 라이브러리 등 함께 사용할 기술 스택을 정해 주세요.
6. API 데이터 형식이 팀에서 합의한 내용과 일치하는지 중간중간 확인해 주세요.
7. 브라우저의 모바일 뷰에만 의존하기보다 시뮬레이터 환경에서 개발하는 것을 권장해요.
8. 앱 변환에 필요한 시간을 확보하고, 마감 1~2시간 전에는 변환을 진행하는 것을 권장해요.
9. 애니메이션은 제외하고 핵심 기능에 집중해 주세요.
10. 마크업처럼 작업이 지연되기 쉬운 부분에는 AI를 활용해 보세요.
11. 상태 관리는 필요한 범위로 최소화해 주세요.
12. 리렌더링 최적화보다 기능 완성을 우선해 주세요.
13. 확장성·결합도·재사용성을 다듬는 작업은 핵심 기능 구현 뒤로 미뤄 주세요.
14. 제한된 시간에는 기능 구현에 집중해 주세요.
15. Figma MCP 등의 AI 도구를 활용해 개발 시간을 줄여 보세요.

# 3. 심사기준

**기본 총점 100점** (가산점 최대 10점)



## 01. 기능 구현 완성도 (30점)
#### 채점 방법
- 기능 구현 완성도에 따라 항목별 점수를 합산해요.
- 핵심 기능의 정상 동작은 20점, 사용자 시나리오 흐름은 5점, 에러·빈 상태 등의 처리는 5점으로 평가해요.

#### 세부 평가 기준
- 핵심 기능을 모두 구현하면 20점, 일부 구현하면 10점, 구현이 미흡하면 0점이에요.
- 사용자 시나리오가 매끄럽게 이어지면 5점, 혼란이 있으면 0점이에요.
- 에러 처리와 빈 상태 처리는 각각 2.5점이에요.
- 사용자가 다음 행동을 이해하고 불필요한 이탈이나 혼란 없이 목표 작업을 완료할 수 있도록 구성해 주세요.


## 02. 디자인 구현 완성도 (20점)
#### 채점 방법
- 디자인 구현 완성도에 따라 구간별 점수를 부여해요.
- 레이아웃, 간격, 타이포그래피, 색상이 일관되게 적용되었는지 확인해요.
- 의도한 디자인이 정확하게 구현되고 다양한 디바이스에서 안정적으로 표현되는지 살펴봐요.

#### 세부 평가 기준
- 전체 화면을 구현하고 완성도가 높으면 20점이에요.
- 주요 화면은 완성했지만 세부 표현이 부족하면 15점이에요.
- 디자인 반영이 미흡하면 10점이에요.
- 구현 수준이 낮으면 5점, 구현하지 못한 경우에는 0점이에요.


## 03. 서버 및 API 연동 (20점)
#### 채점 방법
- 서버와 API 연동 완성도에 따라 구간별 점수를 부여해요.
- 실제 서버 또는 로컬 서버(localhost)와 통신하는지 확인해요.
- 코드를 통해 API 요청·응답 흐름과 실제 데이터 fetch·mutation 로직을 살펴봐요.

#### 세부 평가 기준
- 전체 API를 연동하면 20점이에요.
- 일부 API를 연동하고 목업을 함께 사용하면 10점이에요.
- 2개 이하의 API만 연동하면 5점이에요.
- API 연동 없이 목 데이터만 사용하면 0점이에요.


## 04. 애플리케이션 완성도 (20점)
#### 채점 방법
- 애플리케이션 완성도에 따라 항목별 점수를 합산해요.
- APK 파일의 정상 실행·설치 가능 여부는 10점, 네이티브와 웹의 연결 완성도는 10점으로 평가해요.

#### 세부 평가 기준
- 안드로이드와 iOS의 정상 실행은 각각 5점이에요.
- 웹에서는 동작하지만 앱에서 안내 메시지 없이 동작하지 않으면, 연결 완성도 만점 10점에서 건당 2점을 감점해요.
- 스플래시 이미지를 처리하면 가산점 5점을 받을 수 있어요.


## 05. 팀워크 (10점)
#### 채점 방법
- Git 사용을 중심으로 팀의 협업 방식을 살펴봐요.

#### 세부 평가 기준
- 작업별로 커밋을 적절히 나누면 5점이에요.
- 협업 컨벤션을 잘 지키면 5점이에요.


## 부록. 디자인 구현 완성도 상세 평가지표

- **20점** — 전체 구현 및 완성도가 높은 경우예요.
  - 디자인 의도가 정확하게 반영되고, 레이아웃·간격·타이포그래피·색상의 일관성이 유지돼요.
  - 다양한 화면 환경에서도 레이아웃이 안정적이에요.
- **15점** — 주요 화면은 구현했지만 일부 세부 표현이 부족한 경우예요.
  - 핵심 화면은 대부분 구현했지만 간격·정렬·스타일에 일부 보완이 필요해요.
  - 일부 화면이나 해상도에서 경미한 레이아웃 불안정이 있어요.
- **10점** — 디자인 반영이 미흡한 경우예요.
  - 시안과의 차이가 뚜렷하고 UI 일관성이나 화면 완성도에 보완이 필요해요.
  - 여러 화면에서 레이아웃 불안정이 확인돼요.
- **5점** — 구현 수준이 낮은 경우예요.
  - 기본 화면은 있지만 디자인 반영이 제한적이고 정렬·구조가 불명확해요.
  - 사용하기 어려운 부분이 여러 곳에 있어요.
- **0점** — 구현하지 못한 경우예요.
  - 디자인이 거의 반영되지 않고 화면이 크게 흐트러져 정상적인 사용이 어려워요.
