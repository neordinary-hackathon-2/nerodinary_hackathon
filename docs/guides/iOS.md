# 1. 시간대별 가이드

> ⏰ **제출 마감 11.22 · 07:30**
> 07:20부터 프로젝트를 제출해 주세요. 발표 준비 중에도 07:30 제출 마감을 지켜 주세요.


## 01. 16:40—19:00 — 아이디어와 초기 세팅
- 사용할 프레임워크(UIKit, SwiftUI)를 정해 주세요.
- 최소 OS 버전 등 프로젝트 초기 설정을 진행해 주세요.
- 주요 기능의 구현 우선순위를 정해 주세요.
- Git 브랜치와 협업 환경을 설정해 주세요.
  - 한 명이 대표로 초기 프로젝트를 생성하고 파일과 GitHub 규칙을 공유해 주세요.


## 02. 19:00—05:00 — 프로젝트 개발
- Assets를 미리 준비해 주세요.
  - 폰트, 자주 사용하는 메인 컬러, 이미지 등을 정리해 주세요.
- 필요한 Package와 Library를 설치해 주세요.
- 디자인이 완료된 순서대로 역할을 나누고 화면 구현과 API 연동을 시작해 주세요.
  - 주요 기능을 기준으로 개발 우선순위를 정해 주세요.
  - 코드가 겹치지 않도록 역할을 나눠 주세요.
  - 탭바가 있다면 탭을 기준으로 UI를 나눠 구현한 뒤 화면을 연결하는 것을 권장해요.
  - 충돌을 줄이기 위해 한 코드 파일은 한 명이 수정하도록 조율해 주세요.


## 03. 05:00—07:40 — 최종 점검과 발표 준비
- 서버를 연동해 주세요.
  - 공통 코드와 오류를 공유하기 쉽도록 Alamofire, Moya 등의 라이브러리를 통일하는 것을 권장해요.
  - 주요 기능 완성을 목표로 API 연동 순서를 정해 주세요.
- 오류를 수정해 주세요.
  - 뷰 연결과 Auto Layout이 의도한 대로 동작하는지 확인해 주세요.

# 2. 유의사항

1. 과도한 애니메이션은 줄여 주세요.
2. 빠른 UI 구성을 위해 가능하면 SwiftUI를 활용해 주세요.
3. MVVM, MVC, MVP 중 팀에 맞는 아키텍처를 빠르게 정해 주세요.
4. Socket, SSE 같은 실시간 통신은 가능한 한 제외해 주세요.
5. 시간 내 완성을 위해 Tab Bar(바텀바)는 최대 2개 영역으로 구성해 주세요. 3개 이상으로 늘리면 완성이 어려울 수 있어요.
6. 전체 뷰는 최대 6개, 1명당 3개의 Feature를 기준으로 범위를 정해 주세요.

# 3. 심사기준

**기본 총점 100점** (가산점 최대 10점)



## 01. 서버 통신 (15점)
#### 채점 방법
- 임시 데이터 대신 실제 서버와 통신하는지 확인해요.
- 네트워크 오류와 잘못된 데이터를 처리하며 정상적으로 통신하는지 살펴봐요.

#### 세부 평가 기준
- API를 연동하지 않고 하드코딩 된 경우에는 0점이에요.
- API를 연동했지만 부분적으로 연동을 한 경우에는 10점이에요.
- API를 모두 연동한 경우에는 15점이에요.


## 02. UI 완성도 (10점)
#### 채점 방법
- Figma 시안과 일치하는지, 터치했을 때 의도한 동작이 이루어지는지 살펴봐요.

#### 세부 평가 기준
- 기획 방향이 UI 전반에 잘 반영되었는지를 기준으로 10점을 평가해요.


## 03. 크래시 안정성 (20점)
#### 채점 방법
- Release 빌드를 사용하며 크래시가 발생하는지 확인해요.

#### 세부 평가 기준
- Release 빌드에서 크래시가 발생하면 이 항목은 0점이에요.


## 04. 기능 동작 완성도 (20점)
#### 채점 방법
- Release 빌드로 앱을 실행하고, 기능명세서를 기준으로 주요 기능의 동작을 확인해요.

#### 세부 평가 기준
- 기능명세서를 기준으로 평가해요.
- 메인 기능이 구현되지 않은 경우에는 0점이에요.
- 메인 기능은 구현됐지만 추가적인 기능들을 구현하지 못한 경우에는 10점이에요.
- 모든 기능을 구현했지만 하드코딩이 된 부분들이 존재하는 경우에는 15점이에요.
- 모든 기능을 정상적으로 구현한 경우에는 20점이에요.


## 05. 코드 가독성 (20점)
#### 채점 방법
- 전체 코드의 의도와 흐름, 효율성을 살펴봐요.

#### 세부 평가 기준
- 의도 전달력: 7점이에요.
- 아키텍처 / 상태관리 일관성: 5점이에요.
- 복잡도 관리: 4점이에요.
- Dead code 유/무: 4점이에요.


## 06. 앱 완성도 (15점)
#### 채점 방법
- Release 빌드를 사용하며 Auto Layout이 적절히 적용되었는지 확인해요.

#### 세부 평가 기준
- 화면 UI를 기준으로 평가해요.
- 기기별 화면 크기 대응 : 5점이에요.
- 다양한 입력 값 대응 : 5점이에요.
- Apple HIG 반영률 : 5점이에요.
