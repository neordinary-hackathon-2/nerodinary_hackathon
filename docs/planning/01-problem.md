# 01. 문제 정의 · 타겟 (논리성 20 · 문제 해결력 20)

> 확정 시각: ____ (목표: 19:00 전, 늦어도 24:00 전)
> 주제 키워드: **콘텐츠(장면) × 제약(처방)** — 볼 거 고르기 × 선택지를 일부러 줄임

## 1. 타겟 사용자 (누가 / 어떤 상황에서 / 무엇 때문에 어려운가)
- 누가: 식사하면서 유튜브·넷플릭스를 보려는 사람 (자취생·대학생 등)
- 어떤 상황에서: 밥을 먹기 시작할 때. 식사 시간은 약 20분으로 한정되어 있음
- 무엇 때문에 어려운가 (Pain Point 1줄): 뭘 볼지 고르다가 정작 영상은 못 보고 밥이 끝난다

## 2. 현재 해결 방식과 그 한계
- 지금 사용자는 어떻게 해결하나: 썸네일을 계속 스크롤하거나, 앱을 오가며 탐색하거나, 친구에게 물어본다
- 그 방식의 한계: 선택지가 무한해서 고르는 행위 자체가 피로하고, 보기를 시작한 뒤에도 "더 재밌는 게 있을까"를 계속 의심하게 된다

## 3. 문제 → 원인 → 해결 방향 → 기대 효과
| 단계 | 내용 |
|---|---|
| 문제 | 콘텐츠를 고르는 데 시간을 다 써서 식사 시간에 영상을 즐기지 못함 |
| 원인 | 선택지가 무한하고, 비교·탐색이 자유로워서 결정이 끝나지 않음 |
| 해결 방향 (솔루션 한 줄) | 옛날 TV처럼 **채널 이동을 번호 한 자리·다음 채널로 한정(제약)** 만들어, 고르지 않고 흘러가며 보게 한다 |
| 기대 효과 | 고민 시간 0, 식사 20분 동안 끊김 없이 시청. "고르기"가 "채널 돌리기"라는 놀이로 바뀜 |
